# Математика с нуля

Интерактивный обучающий сайт: математика с самого начала и до арифметики — счёт и ноль, сравнение, числовая прямая, сложение и вычитание, разряды, умножение, деление с остатком и тренажёр.

Каждое понятие показано как маленькая настоящая машина в изометрическом стиле навыка [Anatomy](https://github.com/wheresryan22/anatomy): счётный лоток, рычажные весы, линейка с фишкой, башня с подносом, счёты на стержнях, доска с лунками, раздаточный стол. Фигуры заново проецируются каждый кадр, поэтому их можно поворачивать в 3D (перетаскивание мышью или пальцем, клавиши `[` и `]`, двойной щелчок — исходный вид), а движение идёт на пружинах.

## Запуск

Сборка не нужна — это статический сайт. Откройте `index.html` в браузере или выложите папку на любой хостинг (например, GitHub Pages).

## Устройство

- `js/iso-kit.js`, `css/iso.css` — изометрический кит Anatomy (MIT), без изменений, только без `export`.
- `js/engine.js` — сцена: камера с поворотом, сортировка по глубине, пружины, наклонные тела (`hexa`), надписи на гранях, базовая плита.
- `js/lessons.js` — восемь фигур-уроков и герой.
- `js/app.js` — кнопки, мини-проверки, тренажёр, тема, прогресс чтения.

Тёмная и светлая темы, клавиатура, `prefers-reduced-motion` поддерживаются.

## Баннер для ссылки

`og-image.png` (1200×630, тёмный) и `og-image-light.png` — превью для соцсетей и мессенджеров, подключено в `index.html` через Open Graph. Исходник — `banner/og.html`, пересборка: `node banner/render.cjs` (нужен Playwright). После публикации замените в `og:image` относительный путь на полный адрес сайта — некоторые сервисы требуют абсолютный URL.
