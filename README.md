# Математика с нуля — курс на 12 лет

Интерактивный обучающий сайт: 12 лет математики, 48 тем — от счёта и нуля до производной, интеграла, комплексных чисел, определителей и матриц 3×3.

Каждая тема — живая фигура в изометрическом стиле навыка [Anatomy](https://github.com/wheresryan22/anatomy): счётный лоток, весы с иксами, счёты с переносом, шестерни, лифт ниже нуля, логарифмическая линейка, чертёжная доска с графиками (функции, касательная, интеграл, векторы, матрицы 2×2), а для пространственных тем — 3D-сцены на [Three.js](https://threejs.org) в той же графике: многогранники с развёрткой, тела вращения, векторы и векторное произведение, куб под матрицей 3×3, три плоскости системы уравнений. Всё можно поворачивать (перетаскивание, клавиши `[` `]`, двойной щелчок — исходный вид), а параметры менять ползунками.

## Озвучка

Каждый урок читается вслух кнопкой «Слушать урок» (текущий абзац подсвечивается). Источник голоса выбирается в настройках «Голос»:

1. **Записанные файлы** `audio/*.mp3` + `audio/manifest.json` — если они есть.
2. **[VoiceStudio](https://github.com/debpalash/VoiceStudio)**, запущенный у вас (по умолчанию `http://localhost:3900`): сайт вызывает `/health`, `/v1/audio/voices` и `/v1/audio/speech`, как описано в навыке VoiceStudio. Бэкенд должен разрешать запросы со страницы (CORS).
3. **Голос браузера** — выбирается лучший русский: «Natural»-голоса Edge, голоса Google в Chrome и т. п.

Чтобы записать красивый постоянный голос для всех уроков один раз, запустите VoiceStudio и выполните:

```sh
node tools/voicestudio-narrate.mjs --list-voices
node tools/voicestudio-narrate.mjs --voice <id-голоса>
```

Скрипт проверяет `/health`, генерирует каждый фрагмент, убеждается, что ответ — действительно аудио, и пишет `audio/manifest.json`; сайт сразу начнёт его использовать (на хостинге, не с `file://`).

## Запуск

Сборка не нужна — статический сайт. Откройте `index.html` или выложите папку на GitHub Pages. Three.js лежит локально в `js/vendor/`.

## Устройство

- `js/iso-kit.js`, `css/iso.css` — кит Anatomy (MIT), без изменений, только без `export`.
- `js/engine.js` — изометрическая сцена: камера с поворотом, порядок по глубине, пружины, наклонные тела, надписи на гранях.
- `js/plot.js` — чертёжная доска для графиков; `js/three-stage.js` — сцена Three.js в той же графике.
- `js/lessons.js`, `js/scenes-iso.js`, `js/scenes-board.js`, `js/scenes-3d.js` — фигуры.
- `js/course.js` — весь курс: тексты, фигуры, кнопки, вопросы.
- `js/voice.js` — озвучка; `js/app.js` — маршруты, интерфейс, прогресс.

## Баннер для ссылки

`og-image.png` (1200×630, тёмный) и `og-image-light.png` — превью для соцсетей и мессенджеров, подключено в `index.html` через Open Graph. Исходник — `banner/og.html`, пересборка: `node banner/render.cjs` (нужен Playwright). После публикации замените в `og:image` относительный путь на полный адрес сайта — некоторые сервисы требуют абсолютный URL.
